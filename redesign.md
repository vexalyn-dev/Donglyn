THIS IS MANDATORY.

CAPTCHA MUST be verified server-side.

Never trust:

captchaPassed=true

frontend boolean

localStorage

client state

hidden input

cookie created only by frontend

The server must verify the token using the
appropriate official verification mechanism.

Validate where supported:

- success
- token validity
- expiration
- hostname/site information
- action
- other provider response fields

Reject:

invalid
expired
missing
reused

tokens where applicable.


============================================================
CAPTCHA FLOW
============================================================

Example:

USER

↓

CAPTCHA

↓

TOKEN

↓

FRONTEND SENDS TOKEN

↓

BACKEND VERIFIES TOKEN

↓

BACKEND CONFIRMS

↓

LOGIN / REGISTER / PROTECTED ACTION

Never treat frontend state as proof of verification.
